# Identidade visual

Coloque aqui os arquivos oficiais do bloco, mantendo os nomes:

- `logo-mark.svg` — símbolo (usado no header, no admin e nos convites). Hoje é um placeholder.
- Fontes: adicione os arquivos em `src/assets/brand/fonts/` e ajuste `--font-body` e
  `--font-display` em `src/styles/variables.css` (com `@font-face` em `global.css`).

Também troque os ícones do PWA em `public/icons/` (192, 512, maskable 512, apple-touch 180)
e a imagem padrão de compartilhamento `public/icons/og-default.png` (1200x630).
